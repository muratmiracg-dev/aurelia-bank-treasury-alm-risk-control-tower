# Portfolio description

Built an end-to-end Treasury and Asset-Liability Management decision platform that combines
official TCMB market anchors and BDDK sector benchmarks with a controlled synthetic bank
balance sheet. The platform calculates repricing gaps across 19 time bands, EVE under all
six Basel IRRBB shocks, one-year NII sensitivity, liquidity and funding stress, structural FX
open positions, DV01 and partial hedge alternatives. Verified by 46 automated tests and
93.88% code coverage, it converts an FX risk-appetite breach, combined-liquidity stress and
a rapid digital deposit-run vulnerability into an auditable ALCO action queue. Outputs are decision-support evidence, not
trade instructions or regulatory returns.
